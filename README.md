# macOS 风格磨砂检索工作台

一份可随仓库携带的中文设计技能，适用于工程记录、资料目录和文档检索网页。用户先比较命中记录，再打开原文，返回后可从原位置继续。磨砂效果用于导航和工具栏，表格与正文保持清晰。

## 在另一台电脑上使用

从 GitHub 下载仓库 ZIP 并解压，或复制整个仓库目录。在工程中打开技能入口，按相对链接读取设计尺度。两份文件可离线阅读，使用本机已有字体，无需安装字体包或前端依赖。

将以下内容交给能读取该目录的编码助手即可开始工作。

> 请读取 `skills/macos-frosted-search/SKILL.md` 及其设计尺度，检查当前检索页。保留现有数据和查询逻辑，让我能比较结果、打开原文，并从刚才那条记录继续浏览。
