# 磨砂检索网页的设计尺度

以下数值是浅色 Web 工作台的一套实现起点，按 CSS 像素计。字号以 16px 等于 1rem 换算。它们来自网页排版选择，Apple 官方材料提供设计原则。

## 布局与阅读顺序

桌面窗口最大宽度 1650px，左侧目录 204px；主区自上而下排列标题栏、搜索工具栏、当前工作内容、状态栏。标题栏高 56px，状态栏高 32px，搜索表单最大宽度 660px。结果列表与阅读器共用主区的全宽，两种状态分别容纳比较和精读。

- **摘要优先。** 先呈现“检索结果”和命中数量，再呈现当前范围内的筛选与记录表。来源数按来源去重，记录数按命中行统计。多条命中、模糊查询、浏览全库、改变筛选均停留在摘要。业务允许时，无筛选的精准查询只命中一条可直达原文，提供“返回结果”。
- **横向筛选。** 常用、取值少的一组条件可用单选按钮，其余用有名称的下拉框。组内间距 6px，组间横距 10–20px、纵距 9px。下拉宽 88–130px，长名称可放宽至 108–155px；默认最小高 32px。窄处连同组名一起换行。已选值保持可见；多个条件叠加时提供清除入口，并同步筛选后的数量。
- **记录表。** 第一列约占 31%，显示可打开的标题。其余列放区分记录所需的条件、状态和来源。表头内边距约 10 × 9px，正文约 13 × 9px。状态以文字显示；需要区分相近条目时保留稳定标识。先让用户看见记录，再按需展开命中依据或原始字段。
- **阅读器。** 正文纸面最大宽度 760px，水平内边距 19–50px。页首放来源和标题，接着列少量元数据，默认打开有出处的原文摘录。只为确实存在的原始资料显示附图或额外标签页。返回控件置于纸面上方。

## 材质、色彩与层次

使用一幅低对比度、静止的底景贯穿窗口。表中颜色为浅色模式的起始值，透明度为背景填充的 alpha，不能设在容器的整体 opacity 上，否则文字也会变淡。

| 表面 | 填充与透明度 | 模糊 / 饱和度 | 层次提示 |
| --- | --- | --- | --- |
| 目录 | RGB 244 249 251 / 48% | 24px / 114% | 1px 分界线 |
| 标题栏、状态栏 | RGB 249 251 255 / 52% | 19px / 110% | 让底景色透出 |
| 搜索栏、输入框 | 栏 RGB 246 250 254 / 58%，框白色 81% | 栏 19px / 110% | 输入框边界独立可见 |
| 结果表区 | RGB 253 254 255 / 96% | 无 | 以细分隔线区分记录 |
| 阅读器衬底、纸面 | 衬底 RGB 234 239 243 / 85%，纸面白色 100% | 无 | 纸面使用 1px 边线及轻阴影 |
| 临时帮助弹层 | RGB 247 250 253 / 86% | 28px / 112% | 背后加遮罩，关闭后回到触发处 |

正文可从 `#1d1d1f`、次级文字从 `#485761` 起步。可打开的标题使用 `#164f7d`，选中控件使用浅蓝底并加字重或边线。状态色搭配明确文字。窗口边线白色 82%，分隔线可用深灰蓝 15%，大阴影只用于窗口、抽屉和弹层。表格单元依靠间距和线条分组。

## 字阶、间距和圆角

| 用途 | 字号 / 行高 | 字重 |
| --- | --- | --- |
| 资料标题 | 22–33px / 1.32 | 650 |
| 结果区标题 | 20–24px / 1.3 | 650 |
| 记录标题、搜索输入 | 15px / 1.4–1.5 | 标题 600，输入 400 |
| 摘录正文 | 15–16px / 1.75 | 400 |
| 表格值、导航、结果数 | 14px / 1.4–1.55 | 400–500 |
| 表头、筛选标签、来源 | 12–13px / 1.5 | 说明 400，标签 550–600 |

采用本机系统无衬线字体。数字计数用等宽数字，原始标识允许折行或选取复制。空间以 4、8、12、16、24、32px 为基础，紧密组合可用 6px；分组前后留 16–24px。圆角从内向外增加，纸面 3px、按钮与筛选 6px、目录选项 7px、搜索框 8px、帮助弹层 17px、桌面窗口 20px。输入框高 36px，图标通常 16–20px。

## 窄屏与实色模式

| 视口或偏好 | 调整 |
| --- | --- |
| 宽度 ≤1120px | 窗口铺满视口并去掉外圆角及阴影；保留 176px 目录。 |
| 宽度 ≤900px | 目录默认收起，以 230px 宽抽屉展开；主区随页面滚动。 |
| 宽度 ≤680px | 标题栏和搜索栏可吸顶，按实测栏高为焦点和正文留出空间。列表改为两列字段，标题与来源各通栏。筛选下拉约宽 100px、最小高 35px，组间距 7 × 12px，容许换行。 |
| 用户或系统降低透明度、增强对比度，或浏览器不支持后景模糊 | 隐去底景与模糊；目录用 `#e8edf0`，工具栏用 `#f1f3f5`，结果区用 `#fbfcfd`，阅读器衬底用 `#edeff1`。手动开关要有名称，系统偏好优先。 |
| 强制颜色或减少动态效果 | 强制颜色使用系统底色、文字色及焦点轮廓；减少动态效果时直接切换状态，保留焦点、选中反馈和返回位置。 |

## 键盘与状态

- Windows 的 Ctrl+K、macOS 的 ⌘K 聚焦搜索输入，Enter 执行查询。Tab 能找到搜索、每组筛选、记录标题及返回按钮。焦点轮廓可用 3px，外偏移 2px；在亮底、实色模式和强制颜色下逐项查看。
- 用有文本名称的链接或按钮打开记录；点击整行可以作为辅助。返回时恢复原查询、筛选值、列表滚动位置和触发控件焦点。Esc 优先关闭最上层弹层，其次可退出阅读。
- 打开模态目录或帮助时将焦点移入，限制 Tab 留在其中，关闭后归还焦点。详情页标签用左右方向键切换，Home、End 到首尾；选中语义与面板内容同步。
- 在实际视口检查底景最亮和最暗处的文字对比。实色后仍应能辨认当前选择；放大文字后筛选组可换行，窄屏滚动时焦点不被固定工具栏盖住。

## 文案减法

“筛选”下方的“可以使用这些条件筛选下方结果”可以删掉。如果侧栏面向全库，而横向筛选只作用于当前命中，就保留“在当前结果中筛选”来区分范围。搜索框已有“搜索”按钮时，仍给输入框关联“搜索资料”名称。输入要求、无结果原因及可用的重试方式在实际需要的状态出现。可直接复用[文案减法提示](../SKILL.md#文案减法)。
